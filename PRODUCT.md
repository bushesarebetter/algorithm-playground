# Algorithm playground

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript modules. The browser experiments run without an application server or runtime dependencies. GitHub Pages is the selected public hosting path.

## Users

Visitors who want to inspect algorithms, simulations and small machine learning experiments, try their mechanisms and follow the original project source.

## Product Purpose

Present the bushesarebetter project collection clearly and make selected mechanisms directly explorable in a browser.

## Operating Context

The gallery connects existing Python projects and paper implementations with their source, notes and available visual assets. Browser engines are JavaScript ports. The collection presents twenty classic projects and six paper implementations.

## Capabilities and Constraints

- Compare seeded maze generation and BFS, Dijkstra and A* search playback.
- Adjust a boids flock, pause it and advance individual fixed steps.
- Play Connect Four against alpha-beta search or Monte Carlo tree search.
- Explore engineering notes, the Security Log Analyzer source, reproducible paper benchmarks and the isolated ReceiptScanner sample workflow.
- Preserve the original implementations while adding browser experiences.
- Use actual measured runs for benchmark claims; animation speed is not a runtime benchmark.
- Keep the fluid cover's illustration credit distinct from numerical project output.
- Keep synthetic log and fictional receipt examples visibly labeled.
- The public receipt workflow must not expose its local backend or databases.

## Brand Commitments

The approved world is a polished Apple-inspired visual project gallery: white and cool light-gray surfaces, precise grotesk typography, generous measured space, blue actions and substantial project imagery. Use the established GitHub handle without adding personal credentials, identity claims or affiliations.

## Evidence on Hand

Existing project source and READMEs, numerical project images, source-linked engineering notes, benchmark records, and working browser implementations support the presentation. The user selected the first collection mockup with “build 1” on October 22, 2026, approved the expansion plan, and explicitly approved the presentation assets. The finish verdict records ship for the reviewed gallery and playground scope.

## Product Principles

- Let visitors inspect actual projects and interact with selected mechanisms.
- Ground explanations, results and status claims in available evidence.
- Make the route from project preview to working experiment or source clear.
